# spike-html-apps-tooling

spike-html-apps-tooling is the browser-test and screenshot tooling the
[spike-html-apps](https://github.com/JaimeStill/spike-html-apps) repositories share: a driver for
Chrome over the DevTools Protocol on a pipe, with no client library, a page wait, a static server,
and the screenshot bin. It has no runtime dependency and is released by tag. This context records
only working knowledge the code and the README do not express.
